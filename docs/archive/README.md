# ToolHub Documentation Archive

このフォルダは、完了済みの調査記録、過去の実装計画、検証結果、古い handoff を保管する場所です。

通常の実装・検証・配布作業を始めるときは、まず [../README.md](../README.md) とトップレベル docs を読んでください。archive 内の文書は、過去の経緯や判断理由を追う必要がある場合だけ参照します。

## Folders

- `historical/`: 現在仕様と異なる前提を含む古い計画や旧版の主文書。
- `implemented/`: 実装済み、または現在は guardrail としてのみ残す調査・handoff。
- `evidence/`: 特定日の検証結果や一時的な調査 evidence。

## Reading Rules

- archive 内の記述を現在仕様として扱わない。
- 現在の App Studio 通常登録は `shared-env` 固定です。古い `frozen-folder` 標準の説明は historical として扱ってください。
- archive 内のリンクが移動前のパスを指している場合があります。履歴記録として保持し、必要な場合だけ個別に追跡してください。

# ToolHub Concept

ToolHubは、既存および将来追加されるPythonアプリケーションを1つの入口から利用できるようにする業務用ランチャーです。

## 方針

- ToolHubは巨大な統合アプリではなく、アプリポータルとして実装する。
- 各アプリは `apps/<app_id>/app.yaml` を持つ独立したプラグインとして追加する。
- ランチャー本体はアプリ一覧、検索、カテゴリ絞り込み、説明表示、起動要求だけを扱う。
- 個別アプリの起動差分は `runner/` に集約する。
- 利用者画面には内部技術、実行方式、パス、依存関係を表示しない。

## 対象アプリ

- GUIを持つPythonアプリ
- ターミナル上で完結するCLIアプリ
- Web自動化を行うPythonアプリ
- 既にexe化済みの外部アプリ

## 利用者体験

利用者は技術的な違いを意識せず、以下だけでアプリを選べる状態を目指します。

- アイコン
- アプリ名
- 短い説明
- カテゴリ
- 起動
- 説明を見る

詳細画面では業務上必要な説明を表示します。管理者向け情報は折りたたみ領域に隔離し、初期状態では表示しません。

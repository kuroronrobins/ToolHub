# AgendaSnap v3

This ToolHub app starts the audited, self-contained AgendaSnap v3 Windows frozen-folder package.

- Runner: `exe`
- Entry: `bin/AgendaSnap/AgendaSnap.exe`
- External Python, Node, browser, and development server: not required
- Credentials, sessions, meeting audio, transcripts, minutes, and logs: not included

The package and ToolHub App Pack must be regenerated and verified together whenever the audited executable hash changes.
